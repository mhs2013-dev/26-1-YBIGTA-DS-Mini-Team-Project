BLIP 미니 구현 초보자 설명서

이 문서는 현재 프로젝트의 코드를 처음 보는 사람이 파일 역할, 실행 흐름, BLIP 핵심 개념을 한 번에 따라갈 수 있게 만든 설명 자료입니다.

핵심 문장: 이미지는 image_tokens가 되고, 문장은 input_ids가 되며, 둘은 cross-attention에서 만납니다.

2. 실행 흐름

1더미 이미지와 문장을 만듭니다.
2BLIPMini 모델을 생성합니다.
3이미지를 ViT로 token화합니다.
4문장을 token embedding으로 바꿉니다.
5텍스트가 이미지를 cross-attention으로 참고합니다.
6ITC, ITM, LM loss를 계산합니다.
python main.py

출력은 다음처럼 나옵니다.

BLIP-mini dummy run | images=(2, 3, 64, 64) | text=(2, 32) | image_tokens=(2, 17, 128) | ITC=..., ITM=..., LM=..., total=...
sample text: a small cat on the desk

3. BLIP이 하는 일

BLIP은 이미지와 텍스트를 같이 이해하는 모델입니다. 이미지에 맞는 문장을 찾거나, 이미지 설명문을 만들거나, 이미지와 텍스트를 같은 벡터 공간에 놓는 일을 합니다.

BLIP 논문 개념현재 코드
Image EncoderVisionTransformer
Text EncoderTextTransformer
Image-grounded Text Encoderself.text(input_ids, image_tokens=image_tokens)
Image-grounded Text Decoderself.text.logits(..., causal=True)
Image-Text Contrastive Lossimage_text_contrastive_loss
Image-Text Matching Lossimage_text_matching_loss
Language Modeling Losslanguage_modeling_loss

4. main.py 읽기

config = BLIPConfig()
model = BLIPMini(config)
images, input_ids, texts = make_dummy_batch(config)
out = model(images, input_ids)

config는 모델 조절판입니다. model은 실제 BLIP 미니 모델입니다. images와 input_ids는 모델에 넣을 입력입니다. out에는 중간 결과와 loss가 들어 있습니다.

5. config.py 읽기

BLIPConfig는 모델 크기를 정합니다.

image_size = 64
patch_size = 16
vocab_size = 128
max_text_len = 32
embed_dim = 128
vision_layers = 2
text_layers = 2
num_heads = 4

이 값을 따로 둔 이유는 실험할 때 한 파일만 고치면 되게 하기 위해서입니다.

6. data.py 읽기

현재는 훈련이 목적이 아니므로 진짜 데이터셋 대신 랜덤 이미지와 간단한 문장을 씁니다.

images = torch.randn(len(texts), 3, config.image_size, config.image_size)
input_ids = tokenizer.encode(texts)
shape뜻
(2, 3, 64, 64)이미지 2장, RGB 3채널, 64x64 크기
(2, 32)문장 2개, 각 문장을 최대 32개 token으로 표현

7. vision.py 읽기

VisionTransformer는 이미지를 patch로 쪼갭니다.

64 x 64 이미지
→ 16 x 16 patch가 가로 4개, 세로 4개
→ 총 16개 patch
→ CLS token 1개 추가
→ 총 17개 image token

그래서 출력 shape가 (2, 17, 128)이 됩니다.

8. text.py 읽기

SimpleTokenizer는 문자를 숫자로 바꿉니다. 딥러닝 모델은 문자열을 직접 읽지 못하므로 token id가 필요합니다.

tokenid의미
PAD0빈 칸 채우기
BOS1문장 시작
EOS2문장 끝
UNK3모르는 문자

TextTransformer는 세 가지 방식으로 쓰입니다.

호출 방식역할
self.text(input_ids)문장만 읽는 text encoder
self.text(input_ids, image_tokens=image_tokens)이미지를 참고하는 text encoder
self.text.logits(..., causal=True)다음 token을 예측하는 decoder

9. blocks.py 읽기

TransformerBlock은 자기 자신끼리 attention합니다. 이미지 patch끼리 보거나, text token끼리 보는 데 씁니다.

CrossAttentionBlock은 텍스트가 이미지를 보게 합니다. 이 부분이 이미지와 텍스트가 실제로 만나는 핵심입니다.

10. model.py 읽기

image_tokens, image_feat = self.encode_image(images)
text_feat = self.encode_text(input_ids)
grounded_text = self.text(input_ids, image_tokens=image_tokens)
itm_scores = self.itm_head(grounded_text[:, 0])
caption_logits = self.text.logits(input_ids, image_tokens=image_tokens, causal=True)

여기서 image_feat와 text_feat는 ITC loss에 쓰입니다. grounded_text는 ITM loss에 쓰입니다. caption_logits는 LM loss에 쓰입니다.

11. losses.py 읽기

loss목적
ITC맞는 이미지와 문장을 가까운 벡터로 만듭니다.
ITM이미지와 문장이 맞는 쌍인지 분류합니다.
LM이미지를 참고해서 다음 token을 맞힙니다.

12. 이 구현에서 단순화한 부분

13. 추천 공부 순서

  1. main.py에서 전체 흐름을 봅니다.
  2. config.py에서 모델 설정값을 봅니다.
  3. data.py에서 입력 shape를 봅니다.
  4. vision.py에서 이미지가 patch token으로 바뀌는 과정을 봅니다.
  5. text.py에서 문장이 token embedding으로 바뀌는 과정을 봅니다.
  6. model.py에서 이미지와 텍스트가 만나는 지점을 봅니다.
  7. losses.py에서 세 loss의 목적을 봅니다.
정리: ITC는 이미지와 텍스트를 같은 공간에 놓고, ITM은 둘이 맞는 쌍인지 판단하고, LM은 이미지를 보고 다음 token을 맞힙니다.
